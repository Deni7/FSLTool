# FSLTool — правила проєкту

WPF-утиліта (.NET 10, `src/FSLTool`) для керування контейнерами FSLogix на файловому сервері. Інтерфейс багатомовний (українська й англійська, див. «Локалізація»); документація проєкту — українською.

## Документація — оновлювати разом із кодом

Будь-яка зміна функцій (нова дія, кнопка, колонка, картка, параметр, поріг, команда чи параметр режиму без вікна, файл даних, зміна поведінки чи обмежень безпеки) **в тій самій зміні** оновлює обидва джерела:

1. **Вбудовану довідку** — `src/FSLTool/Docs/Help.md` (українська) **і** `src/FSLTool/Docs/Help.en.md` (англійська, той самий зміст і структура). Вона вбудовується в exe і показується у вікні «Довідка» (кнопка в лівій панелі, F1). Розділи `##` автоматично стають змістом. Підтримувана розмітка описана в коментарі на початку файлу (`MarkdownLite` рендерить лише її).
2. **Документацію проєкту** — `README.md` (таблиця «Можливості», розділи «Безпека», «Режим без вікна», «Примітки»).

Крім того:
- зміни команд і параметрів режиму без вікна дублюються в довідці консолі — `Headless.Help` у `src/FSLTool/Services/Headless.cs`;
- нові типові значення порогів — у таблиці «Пороги» в `Help.md`;
- видалена функція прибирається з усіх трьох місць.

Описуйте поведінку так, як вона реалізована (значення за замовчуванням, обмеження, що пропускається), а не як задумано.

## Локалізація

- Жодного тексту для користувача в коді чи XAML: у C# — `Loc.T("Ключ")` / `Loc.T("Ключ", арг…)`, у XAML — `{l:Tr Ключ}` або `{l:Tr Ключ, Arg={Binding …}}` (`xmlns:l="clr-namespace:FSLTool.Localization"`). Це стосується підписів, підказок, діалогів, статусів, повідомлень журналу, звітів і виводу режиму без вікна.
- Рядки — у `src/FSLTool/Localization/<область>.<мова>.json` (плоскі `"ключ": "текст"`). Кожен ключ додається **одночасно** в `*.uk.json` і `*.en.json`. Фрази з підстановками — один ключ із `{0}`, `{1}`, а не склеювання шматків.
- Логіка не повинна залежати від перекладеного тексту (порівняння з підписом, `StartsWith("Помилка")` тощо) — лише прапорці, enum, коди. Значення, що зберігаються у файлах (фільтри, налаштування), — мовонезалежні коди.
- Перекладений текст не кешувати в статичних полях: обчислювати під час звернення, щоб перемикання мови оновлювало інтерфейс без перезапуску.

## Збірка

```bash
dotnet build src/FSLTool
dotnet publish src/FSLTool -c Release -o publish
```

`publish/FSLTool.exe` — один self-contained exe (x64). Програма вимагає прав адміністратора (manifest), тому повний запуск і операції з дисками можна перевірити лише в підвищеному сеансі.

## Домовленості в коді

- Операції над контейнером — у `ProfileOperations` (блокувальні, з `OpReporter`), запускаються з UI через `MainViewModel.RunOnTargets`, у режимі без вікна — з `Headless`. Кожна операція починається з `EnsureFree`.
- Спільні дані в `%ProgramData%\FSLTool` пишуться через `Storage`/`ProfileStore` (перечитати → змінити → атомарно записати під міжпроцесним блокуванням).
- Кінці рядків: файли, що були з LF, лишаються LF; нові `.cs`/`.xaml` — CRLF.
